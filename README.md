# The Press24

বাংলা নিউজরুমের গেটেড রানডাউন। পিচ থেকে প্রকাশ — ধাপ স্কিপ করা যায় না।

## ডেস্ক

বিষয় নির্বাচক, স্ক্রিপ্ট রাইটার, স্ক্রিপ্ট এডিটর, প্রোডিউসার, প্রেজেন্টার, ভিডিও এডিটর, ভিডিও রিভিউ, সোশ্যাল ম্যানেজার।

স্ক্রিপ্ট পাসের সময় প্রোডিউসার ও প্রেজেন্টার অ্যাসাইন হয়। দুজনেই ডান করলে এডিটিং কিউ খোলে।

## চালানো

```bash
npm install
npm run dev
```

প্রথম অ্যাকাউন্ট অ্যাডমিন হয়।
